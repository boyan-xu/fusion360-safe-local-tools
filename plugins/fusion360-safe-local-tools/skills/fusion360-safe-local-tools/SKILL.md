# Fusion 建模与受控导出

本技能适用于 Fusion 建模和 `FusionSafeLocalTools` 插件。用户当前任务中最新的明确要求优先于以下默认规则。插件代码是工作流辅助，不代表 Fusion 所有功能已经验证，也不能约束用户在 Fusion 中的手动操作。

## 先确认，再操作

- 收到建模任务先检查 Fusion 是否运行；未运行就启动，等待进入可操作状态。启动慢、首次调用超时不等于启动失败。检查窗口、活动文档、Design 工作环境与单位。
- 根据具体任务收集必要信息。复用用户已提供的信息，不使用固定问卷，不重复询问。尺寸、结构、约束、公差、配合间隙、参数关系、目标设计、修改范围、受保护部分、关联影响、文件选项等任何影响结果的重要条件不明时，先问清楚，不能自行建模或修改。只读检查可以继续。
- 把确认的目标文档身份、尺寸/表达式、允许修改范围、不能动的内容、输出要求与用户确认依据记在当前任务 `work/fusion-contract.json`。这不是用户填写表格；由助手根据对话整理，未解决问题保持在 `unresolved` 中。不能自行伪造确认。
- 沿用 Fusion 当前单位及显示精度。API 内部长度通常使用厘米，数值必须通过 UnitsManager/带单位表达式转换，不把输入的毫米直接当内部数值。不能为了方便擅自改用户设置。

## 已有设计与建模

- 默认所有已有模型受保护；修改和批量参数变更先建立独立设计副本并验证副本身份、参数、时间轴、引用关系完整。只有明确授权才改原设计。副本不是扩大修改范围的许可。
- 选中实体、已有名称或当前活动文档不等于授权。明确指定不能动的部分保持不变；若依赖关系会牵动它，说明具体影响并取得同意后才能操作。无法验证影响范围就暂停。
- 选择适合设计的 Fusion 功能，支持通过已验证的 API 或 UI 完成草图、几何约束、尺寸、拉伸、旋转、放样及其他建模；不把能力限定为预设操作清单。使用专项脚本前检查安装版本 API 签名，并检查实际结果。未验证/不可用的功能必须说明。
- 新建和调整参数按已确认的表达式与依赖关系进行。创建用户参数使用 `fusion_workflow.create_parameter`；一般操作可在 `mark_created(design)` 中进行，但仍须检查新增对象和时间轴命名。不要用修改参数的方法偷偷改变未经授权的关联部分。
- ChatGPT 新建实体、组件、草图、特征及可命名时间轴项目名称后加 ` (ChatGPT)`；新建用户参数和模型参数使用 `_ChatGPT`。只标记本次确实创建的对象，不给旧内容批量改名。用户要求去掉标记时只在指定范围移除，核实公式引用仍有效。
- 本地 API 执行必须在 Fusion 主线程。优先现有可用的官方桌面 MCP；若不可用，使用 Fusion 自身 Scripts and Add-Ins 运行审查过的任务脚本，或通过 UI 完成。没有连接工具时不要声称已经执行。此插件没有通用远程 Python 执行服务器。
- 副本策略、脚本导入和能力核实参见 [建模与接口](references/modeling.md)。

## 导入、导出、参数规格

- 只有明确要求导入/导出才操作；建模授权不包含导出授权。确认目标文件、格式、位置、几何范围及影响结果的选项。不得以备份/验证为理由偷偷导出或上传设计。
- 允许按范围/步长、取值集合或组合规则定义规格。明确端点是否包含、组合是全部组合还是逐项配对、参数关联、顺序、预计数量和命名；有歧义继续问，不要求用户列出大量规格。
- 少量规格可给“规格—参数—文件名”表；大量规格确认生成规则、组合方式、数量和命名规则即可。`scripts/expand_specs.py` 使用十进制范围，无浮点步长漂移，拒绝重复文件名及未明确组合。
- 同一参数化设计按规则变更并导出 STEP。先导出并验证一个样本，再开展批量。不要把文件非空视为几何正确：核对真实参数、模型结构、尺寸、健康状态及文件可读性。
- 通用批量程序支持根组件 STEP/STL/3MF；局部几何、其他格式及复杂受保护不变量使用专项脚本/已验证 UI，不能谎称通用执行器支持。具体接口存在不等于实机成功。

## 每个对话持续累计导出大小

所有导出途径（工具、专项脚本、UI、单次、批次和不同格式）共用当前对话的一份账本：固定在本任务 `work/fusion-export-ledger.json`，使用实际对话 ID。记录首次使用路径，后续计划不可另建账本重置额度。已有导出先核对并计入，账本丢失/损坏时暂停恢复，不能从零开始。不要将另一对话的账本当成当前对话。

- 十进制 1 MB = 1,000,000 字节，初始阈值 1,000,000；**严格超过**才暂停，恰好等于不暂停。
- 逐个生成到临时位置并验证。已保存累计量 + 本次待确认文件大小超过阈值时，停止后续导出，报告最后文件的完整字节数/MB、含待确认文件的累计量、已保存量，等待用户决定是否保存。
- 同意则提交该文件，下一阈值 = 当时已保存累计量 + 1,000,000。单文件 5 MB 也只暂停一次，不逐 MB 追问。
- 不同意只删除这个待确认文件，当前规格仍未完成，已保存文件不动。之后明确继续时从当前未完成规格重新生成；不能跳过或重复已完成规格。
- “继续”不等于取消限制。仅用户明确取消时调用取消限制操作；保存/继续后仍执行下一次暂停。
- 账本和规格完成状态必须持久化。记录文件大小、哈希、实际参数、输出路径及暂停原因。文件提交中断时先恢复账本，不重新导出同一规格。
- UI/专项脚本导出同样先用 `Ledger.begin` 取得临时路径，实际生成并验证后 `produced`，不要先输出正式文件再补账。内部副本归档也是文件导出；先明确授权，未经用户明确豁免不要排除累计规则。
- 批量与恢复的具体操作见 [导出工作流](references/export-workflow.md)。

## 警告、报错和恢复

导出过程发现任何黄色警告或红色报错，立即暂停，报告具体项目和信息，请用户检查模型。不得自行判断无关紧要。只有用户检查后明确接受并同意继续，才记录对应规格及对应警告的许可；新的警告、新规格不能继承笼统豁免。用户许可不代表导出成功：Fusion 返回失败、空/无效文件、参数不符都不能记完成，不能跳过。保留规格顺序和完成记录。重试前核对活动文档、副本和参数状态。

## 网络与 Fusion AI

公开资料可以直接联网查阅。向外部服务上传模型、图纸、设计参数前，说明上传什么、上传到哪里、用途并取得用户同意；允许联网不代表允许上传。Fusion AI 同样适用，只用于已确认的小任务，避免复杂大任务导致卡住，检查实际结果，遵守尺寸、范围和命名。Fusion 云端复制/保存也是潜在上传，不能借此绕过确认。此插件自身不连接网络、不启动监听服务、不自动调用 AI。

## 插件维护与如实验收

维护时检查实际注册目录，保持单一运行安装。更新前验证备份并在用户授权范围内更新；不要另装重复实例。保持手动启动，关闭 Run on Startup。停止旧插件后更新已注册路径，通过 Scripts and Add-Ins 运行，检查加载日志、命令、停止和重复启动。卸载先停用，外部注册先 unlink，标准 AddIns 副本才使用卸载脚本。

连接方案变更前读 [连接参考](references/fusion-connections.md)。代码语法/单元测试、API 定义核实和 Fusion 实机验证分开报告。按实际尺寸、参数关系、保护范围、导出结果验收。没有完成、未验证、存在警告或失败时明确说明；不能仅因发出指令就称完成。
